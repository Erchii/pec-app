# PEC-ML Backend

## Quick Start

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Train models (one time)
python train.py

# 3. Start API
python app.py
# → http://localhost:5001
```

## API

### POST /predict

**Minimum input (5 fields):**
```json
{
  "material":    "BiVO4",
  "electrolyte": "KOH",
  "pH":          7.0,
  "bias":        1.23,
  "light_source":"AM 1.5G"
}
```

**Optional extra fields:**
`bandgap`, `temperature`, `light_intensity`, `thickness`,
`cocatalyst`, `synthesis_method`, `photoelectrode_type`,
`nanostructure`, `morphology`, `protective_layer`

**Response:**
```json
{
  "status": "ok",
  "Photocurrent": 4.49,
  "STH":          4.76,
  "H2":           33.76,
  "performance_class": "MEDIUM",
  "units": {
    "Photocurrent": "mA/cm²",
    "STH":          "%",
    "H2":           "µmol/h/cm²"
  }
}
```

### GET /
Health check — shows which models are loaded.

### GET /dataset
Returns the clean dataset as JSON.

## Model Notes

- **Dataset**: 529 rows from literature; many missing values (median/mode imputed)
- **STH model**: Photocurrent excluded as feature (physics leakage: STH ≈ J·1.23/P)
- **H2 model**: log1p target transform (right-skewed distribution)
- **CV folds**: 3-fold (safe for small STH/H2 datasets)
- All models: RandomForest (best CV R² on this data)
