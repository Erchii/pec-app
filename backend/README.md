# PEC-ML Backend

ML-powered prediction of Photoelectrochemical water-splitting performance.
Predicts Photocurrent Density, STH Efficiency, and H₂ Evolution Rate.

## Quick Start

```bash
pip install -r requirements.txt
python train.py --data data/pec_dataset.csv --cv 5
python app.py           # → http://localhost:5001
```

## API

### `POST /predict`

**Required fields:**
```json
{
  "material":    "BiVO4",
  "electrolyte": "0.5 M Na2SO4",
  "pH":          6.8,
  "bias":        1.23,
  "light_source":"AM 1.5G"
}
```

**Optional:** `bandgap`, `temperature`, `light_intensity`, `thickness`,
`cocatalyst`, `synthesis_method`, `photoelectrode_type`, `nanostructure`,
`morphology`, `protective_layer`

**Response:**
```json
{
  "status": "ok",
  "Photocurrent": {"value": 3.34, "confidence": 0.61, "std": 0.15},
  "STH":          {"value": 3.13, "confidence": 0.66, "std": 0.07},
  "H2":           {"value": 41.1, "confidence": 0.52, "std": 5.5},
  "performance_class": "HIGH",
  "performance_score": 71.2,
  "units": {"Photocurrent": "mA/cm²", "STH": "%", "H2": "µmol/h/cm²"}
}
```

### `GET /` — Health check (returns model names and CV R²)
### `GET /dataset` — Full dataset as JSON (676 rows)

## Models

| Target | Algorithm | CV R² | Training rows |
|--------|-----------|-------|---------------|
| Photocurrent Density | XGBoost | 0.454 | 521 |
| STH Efficiency | XGBoost | 0.533 | 556 |
| H₂ Evolution Rate | XGBoost | 0.366 | 559 |

Dataset: 676 rows (529 original + 147 synthetic + physics-derived estimates).
